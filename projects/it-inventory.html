From workbook to web workflow

I built a browser interface for searching assets, looking up network records, adding equipment, and editing existing entries. It brought records from eight tabs into one view and gave staff a place to save follow-up tasks alongside those records.

Making synchronization visible

I implemented import and update workflows with feedback on synchronization status and saved edits. I verified imports against the source workbook across all eight tabs.

Adding device context

I added a Windows reporter for device and connection information and a grouped network view based on inventory records. That let staff review connection observations alongside the assets they had recorded.
