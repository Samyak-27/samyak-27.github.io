Technical teaching

Teaching computer architecture

As a UC Davis teaching assistant, I helped students connect processor architecture to the C and assembly programs they were working through.

Role
Teaching Assistant, UC Davis Computer Science
Dates
Jan 2024 – Apr 2026
Course enrollment
Approximately 300 students per quarter across the courses

Architecture and machine-dependent programming

I supported instruction in Computer Architecture and Machine-Dependent Programming. I explained instruction set design, memory hierarchy, and pipelining, connecting what an instruction asks the processor to do with how the processor carries it out.

Reading assembly and stack frames

I helped students follow instruction execution and register-level computation in assembly. When working through function calls, I explained how registers and the stack frame fit together and where to look for the values a program uses.

Debugging pointers and memory in C

I helped students debug C programs involving pointers, dynamic memory allocation, and segmentation faults. This meant relating a failing memory access to the pointer and allocation it depended on, then using the program’s behavior to narrow down where the error originated.
