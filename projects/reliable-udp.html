Reliable data transfer over UDP

A Python transport project that implements acknowledgments, a sliding window, and timeout-based retransmission over UDP.

Tools
Python sockets, UDP

TCP congestion-control behavior

Tracking data in transit

I designed a packet format with sequence numbers and acknowledgments so the sender could track which packets had arrived. A sliding window allowed it to keep multiple packets in flight while tracking outstanding acknowledgments.

Handling timeouts

I implemented retransmission when an acknowledgment did not arrive within the timeout. To debug socket communication, I inspected the parsed packets and transfer logs to follow how sequence numbers, acknowledgments, and retries changed over time.

Exploring congestion control

I also simulated TCP congestion-control behavior, including how the send window changed and how it recovered after a timeout. That exercise focused on adjusting the amount of data in flight as conditions changed.
