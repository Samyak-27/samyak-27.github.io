Iterative DNS resolver

A Python resolver that builds binary DNS queries, reads compressed response names, and follows referrals to an authoritative server.

Tools
Python sockets and binary parsing
DNS record types
A, AAAA, NS, and CNAME
Resolution path
Root, top-level domain, and authoritative servers

Reading DNS messages

I built queries and parsed binary replies over UDP using Python sockets. I handled IPv4 and IPv6 address records, nameserver records, and canonical names. The parser decoded compressed names, where a pointer in one record refers to bytes elsewhere in the message.

Following referrals

The resolver started at a root server and followed referrals through a top-level domain server to an authoritative server. It used additional address records supplied with a referral when available and could look up the nameserver address when needed.

Tracing a complete lookup

I verified a resolution trace from a root server through the .org servers to an authoritative response that returned an IPv4 address. I then used the resolved address to make an HTTP request and tracked round-trip times during the run.
