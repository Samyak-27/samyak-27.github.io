Computer architecture

Memory hierarchy simulation

I used gem5 to compare translation lookaside buffer sizes and page-walk cache configurations in simulated x86 workloads.

Simulator
gem5 standard library
Workload modes
x86 full-system and syscall emulation
Study variables
TLB size, page-walk cache configuration

What the simulation varied

A translation lookaside buffer (TLB) caches virtual-to-physical address translations. When a translation is missing, the processor can walk the page tables to retrieve it. I varied the TLB size and page-walk cache configuration to study caching at both stages.

Configuring the workloads

I used the gem5 standard library to set up x86 simulations in full-system and syscall-emulation modes. Full-system mode models a guest operating system, while syscall emulation runs a user-space workload with its system calls handled by the simulator.

Comparing configurations

I profiled workloads across the simulation configurations to compare how the memory hierarchy behaved under different translation and caching parameters.
