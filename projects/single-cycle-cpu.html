Computer architecture

16-bit single-cycle CPU

A processor designed and simulated in Logisim Evolution, from the instruction set and control logic to the datapath and memory.

Architecture
16-bit single-cycle processor
Tool
Logisim Evolution
Instruction groups
Arithmetic, branching, and memory operations

Designing the instruction set

I defined an instruction set that supported arithmetic, branches, and memory operations. Each instruction needed control signals that selected the right operands, routed the data through the appropriate hardware, and updated processor state within a single cycle.

Building the datapath

I assembled the arithmetic logic unit, register file, control unit, and memory modules in Logisim Evolution. The datapath connected those modules so the same processor could calculate a result, update the instruction address for a branch, or move data between registers and memory.

Checking instruction execution

I used assembly-level simulation to check the behavior of arithmetic, branching, and memory instructions. I followed changes in the simulated processor state to verify how those instructions exercised the datapath and control logic.
