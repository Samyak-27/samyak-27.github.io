Data automation

Purchasing reports automation

I built a reusable Python workflow that turns purchasing records into Excel reports for recurring purchases, task orders, and monthly spending.

View the workbook tool on GitHub
Organization
UC Pavement Research Center
Tools
Python, openpyxl
Output
Excel reporting workbook

Generating the workbook

I wrote a Python script with openpyxl to read the purchasing records and generate three reporting views. Each answers a different question about the same records, from which purchases recur to how spending is grouped by task order and month.

Comparing reporting months

I added month selectors and a combined-period spending summary so the workbook could answer questions about one or two selected months. The combined view checks for duplicate selections to keep the same month from being counted twice.

Repeating the process

The reporting logic lives in a reusable script that can regenerate the Excel workbook as new purchasing records become available.
