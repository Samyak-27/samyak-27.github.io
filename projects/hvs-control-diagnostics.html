Research systems diagnostics

HVS control software diagnostics

I investigated startup and communication faults across Windows, NI instrumentation, and legacy control software supporting a Heavy Vehicle Simulator.

Organization
UC Pavement Research Center
Scope
Control startup and instrument communication
Tools
PowerShell, NI MAX, USB and serial diagnostics

Checking each part of the connection

I separated the workstation network interface, NI data acquisition configuration, and control application into individual checks. That helped me trace which parts of the system could communicate before investigating how the control software initialized.

Comparing processes and settings

I used PowerShell to inspect startup behavior and found overlapping instances during initialization. I compared machine configurations and found differences in the parameter sets used by the legacy control software.

Testing the instrument connection

I checked USB and serial connectivity independently of the control application. The individual connection checks and configuration findings helped narrow the next investigation to application startup and its communication path.
