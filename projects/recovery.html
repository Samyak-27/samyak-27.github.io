Windows backup & recovery lab

An offline backup toolkit and a portable Windows test environment for checking how recorded data survives interruptions.

Organization
UC Pavement Research Center
Validation
Three synthetic interruption tests
Tools
Windows 11, UTM, PowerShell

Building a portable test environment

I configured a Windows 11 virtual machine in UTM with separate system and data disks. I also built an offline backup toolkit with disk inventory, destination-drive checks, and logs so an operator could verify which drive was being backed up and where the copy would go.

Checking the recovered data

I used a synthetic data acquisition program to write sequentially numbered test records, then interrupted recording and checked the recovered files. All three runs passed the sequence checks for missing records and SHA-256 verification for file integrity.

Documenting the procedure

I drafted separate procedures for system-drive recovery and GNU ddrescue, including drive-identification checks, training checklists, and supervisor review. The recovery results above come from the virtual test environment and its synthetic records.
